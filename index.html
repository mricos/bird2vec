Architecture · WaveGAN (Donahue, McAuley, Puckette · 2018 · arXiv:1802.04208)

Confirmed from wavegan_generate.ipynb + bird2vec_generate.ipynb: loads wavegan-v1 checkpoints, latent z ∈ R100 ~ U[−1,1], generator emits 16384-sample raw waveform at 16 kHz (~1 s). Trained on the Kauaʻi field-recording set (wgtrain-stream-kauai-6-2sec). Not wav2vec 2.0 (contrastive SSL); not VAE.
G maxD 𝔼[D(x)] − 𝔼[D(G(z))] + λ · 𝔼[(‖∇x̂D(x̂)‖₂ − 1)²] (Wasserstein + gradient penalty, λ=10) • Inference: only G runs · tensors z:0 → G_z:0 in the TF1 graph · 64 "jewels" sampled per batch in the notebook. • Dataset here: Kauaʻi forest stream + bird recordings · 2-sec clips · trained ~2403 steps (wgtrain-stream-kauai-6-2sec).
Confirmation: The earlier link (arXiv:2210.15310, wav2vec 2.0 for music) does not match this codebase. WaveGAN is generative-adversarial (G vs D, WGAN-GP loss); wav2vec 2.0 is contrastive self-supervised (encoder → transformer → quantizer). Different families. This pak is WaveGAN.
